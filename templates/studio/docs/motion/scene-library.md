# Scene Library (10 types)

Format per scene: Use when / Layout / Assets and textures / Animation / Pitfalls.
Durations and easings marked [TBD-measure] must be replaced with measured values from reference videos.

## S1. A-roll + captions
- Use when: opening, announcing a new idea, returning to the speaker's face.
- Layout: speaker upper third, captions lower third. Lines of 5 words or fewer; key word largest, centered, in accent font; other words smaller above/below.
- Animation: word-timed pop/fade. [TBD-measure] in-duration 150-250 ms.

## S2. B-roll + text
- Use when: describing an action or scene ("fighting and resisting").
- Assets: stock footage matching the line; light paper texture, darkened and slightly blurred edges (vignette).
- Text: same caption logic as S1, placed to describe the scene.

## S3. Painting + text
- Use when: philosophical or historical point; a person's story.
- Assets: public-domain painting (e.g. from Wikimedia Commons) with paint and rough-paper texture.
- Layout: text around the painting's main subject.
- Animation: quick camera slide-in reveal. Texture must move WITH the painting (a common bug: static overlay).

## S4. Line + text
- Use when: a thought that continues across keywords (three ideas connected).
- Background: black or white with paper texture. Line in accent blue; text interrupts the line, line resumes into related text; camera tracks the line.

## S5. Line + illustration
- Use when: progression through phases or a labeled object.
- Variants: horizontal line with a white dot marking the object, text label, illustration below; zigzag line with camera pan revealing objects on both sides; line leading up to the subject.

## S6. Text-centric (quote)
- Use when: closing statement or punchline.
- Background: white or blue with very rough paper texture; opening and closing quotation marks around centered text. Quote marks are required.

## S7. Center illustration + text
- Use when: one main idea or a person.
- Layout: rough painted illustration in lower half bleeding into upper middle with abstract edges; text around it. Variants: top-down brain, circular thin-line pattern, side profile with rough cloth texture for contrast.

## S8. Side illustration + text
- Use when: two elements at once.
- Layout: abstract character or half-circle on one side (rough cloth texture), text on the other; text may rotate around a half circle.

## S9. Object + text
- Use when: one element as story beat (e.g. photo of the person).
- Layout: paper background, object centered, text around, rough reveal animation.

## S10. Graph / statistics
- Use when: numbers, growth, steady vs volatile.
- Background: flat dark with texture, thin glowing white grid; a blue ball traces the line while the camera follows. Step-climb version: one step per spoken "up".

## Scene selection logic
| Speech moment | Scene |
|---|---|
| Announces a new category/idea | S1 A-roll |
| Describes a person | S7 / S8 character |
| Describes an action | S2 B-roll |
| Anecdote about the speaker | S9 object (photos) |
| Numbers, trend, "slow and steady" | S10 graph |
| Sequence or connected keywords | S4 / S5 line |
| Philosophical statement | S3 painting |
| Final takeaway | S6 quote |

## Variety rules
- Never repeat a scene type consecutively; alternate A-roll with designed scenes.
- Minimum 3 distinct scene types per 30 s.
- First designed visual should land by second 3-5 (see hook rules).
