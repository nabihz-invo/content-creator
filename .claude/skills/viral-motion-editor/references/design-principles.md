# Design Principles

Distilled from two tutorial transcripts. Each rule is actionable.

## 1. Typography
- Four families: serif (book/article feel, accent), sans (modern, captions/UI), script (handwritten, accent), display (textured, use rarely and randomly).
- Pick ONE modern sans as main (~80% of all text) and ONE serif or script as accent for highlighted words.
- Reference pairing from the minimal style: Inter + Playfair Display Italic.
- Smaller text reads as more premium; overlays use 1-2 lines.

## 2. Placement (rule of thirds, 3x3 grid)
- Center cell = focal point: speaker, main subject, or main graphic.
- Outer cells = secondary focal points: subtitles, filler graphics, secondary elements.
- Portrait (9:16): speaker in upper third, captions in lower third. If UI or icons are added, shift captions so the center of the whole group sits in the lower third.
- Half-and-half layouts (speaker on one half, animation on the other) are currently trendy.

## 3. Balance
- Divide the frame in halves (horizontal, vertical, diagonal). Two objects must sit in opposite halves, never both in one.
- Landscape/full-screen: balance horizontally. Portrait: balance vertically.
- Diagonal layouts: one element large, one small; if the front element is the focus, desaturate the back one.

## 4. Contrast (how to direct attention)
- By color (background vs object), by texture, by size (focal element bigger or smaller than the rest), or by shape.
- With two elements, contrast only the one being highlighted.

## 5. Color
- 60 / 30 / 10: primary / secondary / accent.
- Derive the palette from the client brand or the dominant color in the footage; extract a vibrant, a dark and a light shade.
- Palette recipes: analogous (a color plus its two neighbors) and triadic (a Y-shaped pick on the wheel).
- Light backgrounds with dark text feel higher quality than dark with bright text (long-form UI). Minimal style uses paper white or deep blue.

## 6. Branding setup (do this on every new client/raw clip)
1. Colors: dominant color, 60/30/10 palette.
2. Fonts: two fonts fitting the client's market, used consistently.
3. Placement rules: educational/professional uses in-frame rules; funky/cinematic may break them on purpose.
4. Shape language: sharp, slightly rounded, or very rounded, applied everywhere.
5. Animation logic: smooth and slow (let it breathe) or rough and rigid (fast pacing).

## 7. Design from the script
Ask per segment: one object, two objects, a process, a number, a person, a quote?
- One object: focal zone, accent color on the object, contrast via object vs background.
- Two objects: balance, secondary color on both, contrast only on the highlighted one.

## 8. Layout recipes
Horizontal (landscape)
- Object + text: object in one half, text in the other, vertically aligned.
- Object only: focal zone, slightly raised, text right under it.
- Asset/detail: asset scaled past the screen edge filling one half, text in the other half.
- On-screen UI: subject in one half, darken + blur the other half, add text/icons there.

Vertical (portrait)
- One object: object in the focal point in accent color; secondary elements on the edges with blur for depth; text around it (accent font for special words, main font for the rest).
- Object + text: object upper half, text lower half.
- Captions + UI: UI under captions, same width or narrower; icon overlaps text at bottom center or sides; height of UI equals caption height; long assets (testimonials) sit under the text at the same width with a bottom fade.
- Side-by-side: subject one side, blur+darken the rest; text vertically centered with equal edge margins; icon above text at half text size, gap = 2x line spacing.

Short-form scene fixes
- Add thin grid lines or a halftone/paper texture to the background.
- If a scene looks empty, add blurred and faded elements in the top-left and bottom-right corners.
- Highlight one word in the accent font inside a sans sentence.

## 9. Inspiration workflow ("steal like an artist")
- Save screenshots of designs worth reusing; steal colors, layout or fonts, not the whole piece.
- Keep a board organized by scene type (one-object, two-object, diagonal, UI, text...).
- Break any reference into: assets -> effects (blur, desaturation, halftone, texture) -> intro animation (pop, fade, constant rotation, letter-by-letter).
- Plan the edit by pairing each script segment with a board reference before building.
